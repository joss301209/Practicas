Menú principal de actividades del Segundo Parcial

1. JavaScript

En estos ejercicios utilizo principalmente las etiquetas <script> para insertar y ejecutar el código de JavaScript directamente dentro del documento HTML, y la etiqueta <h1> para los títulos principales. Los utilizo así porque permiten una ejecución inmediata y dinámica en el navegador mediante cuadros de diálogo (prompt, alert) y la escritura directa en el cuerpo de la página (document.write).

  • Aprendiendo JS
  • Suma de dos números
  • Resta de dos números
  • Multiplicación de dos números
  • División de dos números
  • Operaciones básicas combinadas
  • Datos del Estudiante

2. Estructuras Condicionales (if-else y switch)

Aquí empleo etiquetas estructurales combinadas con la lógica condicional de JavaScript. Utilizo if-else para evaluar decisiones de dos caminos (como validar si un número es positivo o negativo, o si es mayor de edad) y la estructura switch para manejar múltiples opciones ordenadas en un menú (como elegir qué operación matemática realizar), facilitando la lectura del código y controlando diferentes flujos según lo que el usuario elija.

  • Validación de mayoría de edad para votar
  • Número Positivo o Negativo
  • Promedio (Aprobado o Reprobado)
  • Números Mayores y Menores
  • Asignación de Laboratorio
  • Datos Personales
  • Menú de opciones matemáticas

3. Estructuras Iterativas (While y For)

Estas estructuras se implementan dentro de bloques <script> para realizar tareas repetitivas o bucles. Empleo el ciclo for cuando sé exactamente cuántas veces se debe repetir una acción (un número determinado de pasos), y el ciclo while cuando la repetición depende de que se cumpla una condición abierta (por ejemplo, pedir un dato hasta que el usuario introduzca el valor correcto).

  • Ejemplo de Estructura For
  • Ejemplo de Estructura While

4. Métodos Get (Manipulación del DOM)

En este bloque utilizo etiquetas HTML semánticas y de contenido como <h1>, <p>, <div> e <input> junto con los selectores del DOM de JavaScript (como getElementById, getElementsByClassName, etc.). Los uso para interactuar directamente con los elementos de la página y modificar sus propiedades, atributos o estilos dinámicamente desde el script.

  • Cambiar color a un elemento por ID
  • Modifica estilos por clase
  • Contar elementos por atributo name
  • Modifica etiquetas HTML mediante índice

5. Funciones

Las funciones en JavaScript son bloques de código reutilizables diseñados para realizar tareas específicas que ayudan a evitar la repetición de instrucciones, organizar mejor el programa y hacer las páginas web mucho más interactivas. Para lograrlo, podemos implementar diferentes modalidades según nuestras necesidades, abarcando desde funciones declaradas y con parámetros hasta aquellas que devuelven valores con return, funciones anónimas o flecha para código más corto, funciones asociadas a eventos del usuario, e incluso funciones recursivas que se llaman a sí mismas para resolver problemas paso a paso.

  • Funcion Declarada
  • Funcion Anonima
  • Funcion (Mediante un evento)
  • Funcion con Flecha
  • Funcion con Parametros
  • Funcion con retorno
  • Funcion Recursiva

6.Métodos HTML y JavaScript

Los métodos de HTML y JavaScript trabajan en conjunto para dar dinamismo a las páginas web, permitiendo que el lenguaje de marcado estructure el contenido mientras que JavaScript utiliza sus métodos integrados —como getElementById para manipular elementos del DOM o funciones de interacción como alert y métodos de consola— para procesar datos, responder a acciones del usuario y modificar la interfaz en tiempo real de manera fluida.

  • Cambiar texto
  • Agregar una imagen
  • Mostrar un mensaje
  • Cambiar color de un botón
  • Obtener elemento por clase
  • Deshabilitar un botón
